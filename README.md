# Ant Colony Command

##https://ant-colony-2d.onrender.com

Ant Colony Command is a browser-playable 2D top-down ant colony defense game built with HTML, CSS, JavaScript, and HTML5 Canvas only.

You manage a growing colony, protect the queen, gather food, spawn new ants, and survive increasingly dangerous enemy waves through a full day and night cycle.

## Features

- Top-down real-time colony defense gameplay
- Worker ants that gather food automatically
- Soldier ants that patrol and defend the nest
- Queen ant inside the nest
- Food economy with spawn costs and cooldowns
- Enemy waves with multiple enemy types
- Pheromone-based worker behavior
- Obstacle avoidance
- Day and night survival cycle
- Canvas-based rendering with no external libraries

## Controls

- `W / A / S / D` or Arrow Keys: Move camera
- `Space`: Spawn worker ant
- `E`: Spawn soldier ant
- `Left Click` on nest: Refocus on the colony

## How To Play

1. Start the colony from the menu.
2. Let worker ants gather food from food sources around the map.
3. Spend food to spawn more workers and soldiers.
4. Defend the nest and queen against enemy bugs.
5. Survive long enough or reach the food goal to win.

## Run Locally

This project does not require a build step.

Just open `index.html` in your browser.
